MUYING demo media
================

These are local demonstration assets. The titles, creator names, view counts,
dates and displayed durations in src/data.ts are fictional interface sample data.
All sample video entries play the same original 8-second demo.mp4. Their artwork
is illustrative and is not a frame from the demo video.

Original illustrations
----------------------
city-night.svg, rain-city.svg, coast.svg, mountains.svg, lake.svg,
open-road.svg, forest.svg, quiet-room.svg, light-study.svg
Created specifically for the MUYING prototype with local vector geometry,
gradients, seeded procedural shapes and SVG filters. No third-party artwork.
The reproducible illustration generator is generate-assets.py in this directory.

Original demonstration video
----------------------------
demo.mp4 was generated locally with FFmpeg 7.1.5 using an original animated
color-field expression. No third-party footage, music, fonts, or text is used.
Duration: 8.000 seconds. Resolution: 1280 x 720. Frame rate: 24 fps.
Encoding: H.264 / AVC, yuv420p, MP4 container, fast-start metadata.
The video has no audio track.

Network note
------------
images.unsplash.com returned HTTP 403. No Unsplash image was downloaded.
No MDN footage was downloaded; the original generated video is used instead.
